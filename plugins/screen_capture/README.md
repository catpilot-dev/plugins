# Screen Capture

Tap a button on screen to save a screenshot.

## How to use it

A dim white camera icon sits at the bottom-center of the screen. Tap it, and
a brief white flash confirms the capture.

Offroad, the screenshot is saved immediately. Onroad, the screenshot appears
automatically a few minutes after you park — named by the moment you tapped,
in local time.

It can be toggled ON/OFF in **Plugins → Screen Capture**.

## Check screenshots

Open http://catpilot.local/screenshots to view, download, or delete
screenshots.

Or pull them off the device with:

```bash
scp c3:/data/media/screenshots/*.png .
```
